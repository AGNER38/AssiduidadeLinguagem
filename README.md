README - Aplicação de Visualização de Dados Estatísticos

Descrição

Esta aplicação foi desenvolvida em Python utilizando Tkinter, Pandas, Matplotlib e Seaborn para permitir a visualização e análise de dados estatísticos a partir de ficheiros CSV.

Funcionalidades:
- Carregar ficheiro CSV
- Visualização dos Dados
- Estatísticas Descritivas
- Matriz de Correlação
- Histograma
- Scatter Plot
- Box Plot

Tecnologias Utilizadas:
- Python 3.x
- Tkinter
- Pandas
- Matplotlib
- Seaborn

Instalação:
pip install pandas matplotlib seaborn

Execução:
python main.py

Possíveis Melhorias:
- Exportação de gráficos em PNG
- Escolha dinâmica das colunas
- Dashboard estatístico completo
- Integração com bases de dados
